# VigIA — Prototype d'extension (code source)

Fichiers :
- "VigIA - Prototype extension.dc.html" — le composant (template + logique).
- browser-window.jsx — l'habillage de fenêtre navigateur (dépendance).
- support.js — le runtime des Design Components (requis).

## Lancer
Ouvrir "VigIA - Prototype extension.dc.html" directement dans un navigateur
(les 3 fichiers doivent rester dans le même dossier).

## Interactions
- Cliquer « Vérifier … avec VigIA » sous chaque publication (vidéo, lien, profil).
- Ou ouvrir le popup de l'extension (bouton VigIA en haut à droite) puis
  « Tout vérifier sur cette page ».
- « Réinitialiser la démo » remet les modules à l'état initial.

Système visuel : direction « Sentinelle » — vert #0A5C42, rouge #C8102E,
jaune #F2B705 ; typographies Libre Franklin + Bricolage Grotesque.
