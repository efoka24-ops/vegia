Ce que VigIA détecte
4 modules de protection
intégrés dans votre navigateur
🎬

Vérif-Média

Détecte les vidéos et images manipulées par IA (deepfakes). Score de probabilité de falsification en pourcentage.

📰

Vérif-Info

Fact-checking automatique des textes et publications. Croise avec les bases de données de désinformation connues.

🔗

Vérif-Lien

Analyse chaque URL avant que vous cliquiez. Détecte le phishing, les scams Mobile Money et les arnaques connues.

👤

Vérif-Compte

Vérifie si un compte se faisant passer pour une institution officielle camerounaise est réellement authentique.

Installation manuelle
Testez l'extension en 3 étapes

Chrome ou Edge · Aucun compte requis · Données locales uniquement

1

Télécharger l'extension

Cliquez sur le bouton ci-dessous pour télécharger vigia-extension.zip

2

Activer le mode développeur dans Chrome

Ouvrez chrome://extensions → activez Mode développeur (en haut à droite) → cliquez Charger l'extension non empaquetée → sélectionnez le dossier extrait du ZIP

3

Naviguer sur Facebook ou LinkedIn

Le bouton VigIA vert apparaît automatiquement dans la barre d'outils. Des boutons "Vérifier avec VigIA" s'affichent sous chaque vidéo, lien et profil détecté.

⬇ Télécharger vigia-extension.zip
